# Bits&Bytes Noida

The Noida city fork of [Bits&Bytes](https://gobitsnbytes.org). Teens building and shipping publicly.

innovate. collaborate. hack.

This fork runs independently in Noida. Same floor as the network: the Code of Conduct, the founding principles, the non-negotiables. Everything else is ours to figure out.

> This is a fork, not the parent org. For the canonical Bits&Bytes repo, see [gobitsnbytes/bitsnbytes](https://github.com/gobitsnbytes/bitsnbytes).

---

## What this is

A local instantiation of the same idea: get teens building and shipping publicly, in their own city, on their own terms.

Teen-led. Ships publicly. Everything else adapts.

Read the [Fork Protocol](https://perfect-dinghy-781.notion.site/Fork-Protocol-34049ed2fc33814da57ac2f3f704e519) for what every fork preserves and what it must adapt.

## The floor (non-negotiable)

- Teen-led. Fork leads must be students. Always.
- Ships publicly. Whatever you build, it's visible somewhere: GitHub, Instagram, anywhere.
- Builder culture. We make things. We don't just talk about making things.
- Bits&Bytes in the name. `gobitsnbytes-noida` on GitHub, `@gobitsnbytes.noida` on Instagram.

## The ceiling (ours to define)

- Event format: whatever fits Noida
- Visual identity: our own aesthetic
- Local partnerships: schools, colleges, companies here
- Our accent: Noida has its own tech culture. We lean into it.
